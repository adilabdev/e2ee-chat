# ARCHITECTURE RULES

## RULE 1

features/ hiçbir zaman:

* websocket
* protocol
* reconnect
* retry

bilmemeli.

UI sadece runtime ile konuşur.

---

## RULE 2

Message object sadece:

```text
core/protocol
```

katmanında oluşturulur.

---

## RULE 3

Socket hiçbir zaman doğrudan component içinde yaratılmaz.

YANLIŞ:

```js
const socket = new SocketClient()
```

DOĞRU:

runtime engine yönetir.

---

## RULE 4

Her event idempotent olmalı.

Aynı event 2 kez gelirse state bozulmamalı.

# MESSAGE FLOW

```text
USER SENDS MESSAGE
        ↓
createMessage()
        ↓
runtime engine
        ↓
transport.send()
        ↓
server relay
        ↓
receiver socket
        ↓
runtime store update
        ↓
ACK events
```

---

# MESSAGE STATE MACHINE

```text
PENDING
   ↓
SENT
   ↓
DELIVERED
   ↓
READ
```

Ek state:

```text
FAILED
```

# core/events

## client.events.js

Client event contract.

Örnek:

```js
export const CLIENT_EVENTS = {
  SEND_MESSAGE: "SEND_MESSAGE",
  MESSAGE_READ: "MESSAGE_READ",
};
```

---

## server.events.js

Server → client eventleri.

Örnek:

```js
export const SERVER_EVENTS = {
  SERVER_ACK: "SERVER_ACK",
  MESSAGE_DELIVERED: "MESSAGE_DELIVERED",
  MESSAGE_READ: "MESSAGE_READ",
};
```

---

# core/lifecycle/message.lifecycle.js

Message state transition kuralları.

Örnek:

```js
PENDING -> SENT
SENT -> DELIVERED
DELIVERED -> READ
```

Invalid transition reject edilir.

Bu dosya ileride:

* sync engine
* retry system
* DB reconciliation

için kritik olacak.
